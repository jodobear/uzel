# Uzel agent instructions

Read and follow [`uzel-poc-validated-pack/AGENTS.md`](uzel-poc-validated-pack/AGENTS.md). Work one `work/*.md` slice at a time. The active implementation slice is recorded in [`uzel-poc-validated-pack/STATUS.md`](uzel-poc-validated-pack/STATUS.md).
