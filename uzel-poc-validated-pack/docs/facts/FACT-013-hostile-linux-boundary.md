# FACT-013 — hostile Linux child boundary

- **Claim:** Under the exact pinned Linux POC, a signed malicious-JavaScript napplet cannot use the tested browser surfaces to reach a live loopback listener or execute a Tauri command, while source-bound NAP traffic remains functional.
- **Classification:** verified fact
- **Exact source/pin:** `jodobear/nampplets@d533a63d519c14470f900323958509cdea1c6479`; portable shell assets from `jodobear/nampplets@fc68bce0a4793a8618445e234bcc91d69e8b96de`; `pablof7z/nmp@005dc2a5f12aa414961b313d05ebb021934e385c`; Tauri `2.11.5`, Wry `0.55.1`, and the Nix-pinned Linux WebKitGTK line; hostile aggregate `d29a7660cd37118f9d619a16854617b0d44b20d16b3f6a45b9f8e28ce5187a16`, event SHA-256 `c6183534dc7d46b33c722f9d1771c62ed2a41fc92cfaae07030c6b04608b8bb3`, and artifact SHA-256 `749d4742bde8d42a85f0719f12248203a86ebb9f7f0ace408951f08eb8e15285`.
- **Probe/command:** `pnpm smoke:linux` in the pinned Nix shell; prior `pnpm smoke:fedora` from both the working branch and a detached clean checkout; `pnpm smoke`; `bash scripts/debian-build-smoke.sh`; focused hostile JavaScript tests and Tauri hostile-probe tests.
- **Observed result:** The daemon first proved an ephemeral unprivileged `127.0.0.1` sentinel with a control connection, staged its unique URL through the exact hostile principal/session NAP-CONFIG provider, and only then mounted the exact signed artifact. The child attempted fetch, XHR, WebSocket, EventSource, image, worker, service worker, beacon, media, iframe, form, navigation, and popup paths. It synchronously dispatched the forged invalid-key raw Tauri message before publishing its final report. The host then unmounted the child while the sentinel remained live, covering beacon transfer deferred until teardown. Finalization settled, signaled stop, drained the listen backlog through `WouldBlock`, joined the accept thread, rejected any retained accept-loop failure, and only then sampled the count. The sentinel accepted zero hostile connections and the instrumented application command count remained zero. The verdict was accepted only from the exact child source. User mode hid diagnostics and exposed no unsafe fixture control. `sendBeacon()` queue acceptance was treated only as an attempted probe; the independent sentinel determined transport.
- **Decision:** Accept the CSP plus sandboxed-WebKit boundary for this exact Linux malicious-JavaScript POC. Do not claim resistance to WebKit/browser-engine exploits. Do not wrap the whole Tauri process with Bubblewrap `--unshare-net`; that would also sever trusted loopback daemon and NMP relay traffic. Design per-WebKit-child OS isolation after the POC.
- **Affected documents/code:** `apps/uzel/src-tauri/src/hostile_probe.rs`, `apps/uzel/src-tauri/src/main.rs`, `apps/uzel/src/App.svelte`, `napplets/hostile-egress`, `crates/napd`, `scripts/fedora-run-smoke.sh`, `reports/slice-06-preflight.md`, and `compatibility.lock`.
