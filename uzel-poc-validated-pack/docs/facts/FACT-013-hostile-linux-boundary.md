# FACT-013 — hostile Linux child boundary

- **Claim:** Under the exact pinned Linux POC, a signed malicious-JavaScript napplet cannot use the tested browser surfaces to reach a live loopback listener or execute a Tauri command, while source-bound NAP traffic remains functional.
- **Classification:** verified fact
- **Exact source/pin:** `jodobear/nampplets@e539378ef735ce06651fd94b71e06f9ce757cb13`; portable shell assets from `jodobear/nampplets@fc68bce0a4793a8618445e234bcc91d69e8b96de`; `pablof7z/nmp@005dc2a5f12aa414961b313d05ebb021934e385c`; Tauri `2.11.5`, Wry `0.55.1`, and the Nix-pinned Fedora WebKitGTK line; hostile aggregate `4f69e62d242a6f0d1d13ff7721325906940491037c79fe4c2f0bd61c0f1e1022`, event SHA-256 `56338f7191589eb490ab3a2cfa44acea4a1c09534d6f00de00bebad303869d58`, and artifact SHA-256 `1843ffc7ee9710c207c7097cab5d2a376bb3b94e96ed4b7872db8403c815a828`.
- **Probe/command:** `pnpm smoke:fedora` in the pinned Nix shell, both in the working branch and a detached clean checkout; `pnpm smoke`; `bash scripts/debian-build-smoke.sh`; focused hostile JavaScript tests and Tauri hostile-probe tests.
- **Observed result:** The daemon first proved an ephemeral unprivileged `127.0.0.1` sentinel with a control connection, staged its unique URL through the exact hostile principal/session NAP-CONFIG provider, and only then mounted the exact signed artifact. The child attempted fetch, XHR, WebSocket, EventSource, image, worker, service worker, beacon, media, iframe, form, navigation, and popup paths. After settlement the sentinel had accepted zero hostile connections. A forged raw Tauri message carried an invalid child key and reached WebKit's raw handler, but the instrumented application command count remained zero. The verdict was accepted only from the exact child source. User mode hid diagnostics and exposed no unsafe fixture control. `sendBeacon()` queue acceptance was treated only as an attempted probe; the independent sentinel determined transport.
- **Decision:** Accept the CSP plus sandboxed-WebKit boundary for this exact Linux malicious-JavaScript POC. Do not claim resistance to WebKit/browser-engine exploits. Do not wrap the whole Tauri process with Bubblewrap `--unshare-net`; that would also sever trusted loopback daemon and NMP relay traffic. Design per-WebKit-child OS isolation after the POC.
- **Affected documents/code:** `apps/uzel/src-tauri/src/hostile_probe.rs`, `apps/uzel/src-tauri/src/main.rs`, `apps/uzel/src/App.svelte`, `napplets/hostile-egress`, `crates/napd`, `scripts/fedora-run-smoke.sh`, `reports/slice-06-preflight.md`, and `compatibility.lock`.
- **Revalidate when:** any nampplets, NMP, trusted-shell, Tauri, Wry, WebKitGTK, CSP, navigation policy, fixture byte, child sandbox, or source-binding rule changes.
