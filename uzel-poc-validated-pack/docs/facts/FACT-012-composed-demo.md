- **Claim:** One Linux Uzel window can mount two independently verified napplets and route their interaction through one daemon-owned nampplets/NMP runtime without giving either frame native authority or duplicating NMP state.
- **Classification:** verified fact
- **Exact source/pin:** Rust runtime `jodobear/nampplets@e539378ef735ce06651fd94b71e06f9ce757cb13`; unchanged portable shell assets from `jodobear/nampplets@fc68bce0a4793a8618445e234bcc91d69e8b96de` with SHA-256 `f1a648993468098398a9e46413f7ed3721e2e2fce706ed3452ba1d1f04210f4d` and `55c194631e7e90901dee151bdeb3cdbd93ea1576ed07bb2546d39c2b0ab590be`; transitive `pablof7z/nmp@005dc2a5f12aa414961b313d05ebb021934e385c`.
- **Probe/command:** `pnpm check`; `pnpm test`; `pnpm test:conformance`; `pnpm lint`; `pnpm format:check`; explicit ignored live-NMP test; `pnpm smoke`; `pnpm smoke:fedora`, all through the pinned Nix development shell.
- **Observed result:** The daemon admits only its exact four-fixture catalog and at most four active fixtures. It verified profile-card aggregate `9ee2d7bf...` and follow-list aggregate `eaf4e565...`, created distinct persisted-generation surface tokens, served both artifacts through bounded transfers, completed two NAP-SHELL handshakes, and returned an authored `identity.getFollows.result` under real Fedora WebKitGTK/Weston. Ordinary responses remained source-scoped. The upstream host maps original `MessageEvent.source` objects to exact surface tokens and removes a previous frame mapping on same-ID remount. The shell supplies persisted orientation/ratio with a true 42/58 fresh default, directional DOM focus with explicit Enter-to-iframe interaction, resize, per-pane fullscreen in both orientations, public read identity selection with exact-frame remount and fresh provider reads, source/degradation status, and a bounded type-only developer log hidden in user mode. Its status enters the waiting state before either mount, counts each surface only after the captured child prelude acknowledges exact `shell.init` acceptance over a one-shot transferred `MessageChannel`, and does not overwrite a recorded handshake failure.
- **Rejected assumptions:** A singleton trusted-shell global cannot safely compose two frames because remounting replaces its only mapping. Payload IDs cannot select the target surface. Uzel therefore uses the reviewed portable upstream multi-surface host and returns the runtime-authorized target from the daemon. The automated Fedora harness proves both real frames and responses, but does not synthesize a pointer click inside an opaque-origin nested frame; contract, runtime, and daemon tests prove that interaction seam.
- **Decision:** Keep one daemon, one `RuntimeController`, one NMP engine/store, one trusted top frame, and two sandboxed child frames. Keep fixture discovery closed and POC-only. Permit cross-surface routing only after upstream runtime INC authorization. Retain the signed hostile artifact and full browser denial matrix for Work 06.
