- **Claim:** Uzel can reuse the native runtime without creating a parallel Linux runtime.
- **Classification:** verified fact
- **Exact source/pin:** upstream base [`pablof7z/nampplets@839654c`](https://github.com/pablof7z/nampplets/commit/839654cd3643b430548765823b783f0b5140b8da); reachable 0.29 candidate [`jodobear/nampplets@08ddb87`](https://github.com/jodobear/nampplets/commit/08ddb87a975dcc44c8826e4c9c7fa7cfe7f701bf); Rust 1.89.0; unchanged NMP pin `005dc2a5f12aa414961b313d05ebb021934e385c`.

- **Observed result:** All 16 Rust crates compile and test on Linux with no production Apple cfg edge. Candidate `08ddb87...` also passes 22 Python conformance tests, baseline verification over 52 digested files and 211 envelopes, four trusted-shell tests, full Cargo workspace tests, Clippy with warnings denied, formatting, and file-growth checks. The 0.29 candidate proves a coherent Linux line but remains unratified, advertises no platform domains, and cannot clear Slice 01 until compatibility, security, and NMP-boundary reviewers sign it or Uzel explicitly accepts the exact provisional risks and missing Apple evidence. Do not copy provider, session, storage, exact-build, INC, or NMP logic.
