## Risks

- Spec-less edge probe resolution: acceptance checks 1, 2, 4, and 5 classify PKG-01, PKG-02, PKG-04, and PKG-05; check 3 classifies PKG-03 and explicitly covers idempotent repeat, interruption, and concurrency behavior. No edge item remains assumed away.
- **High — Spoofing/Tampering, ambient `PATH` substitution:** absolute closure-private paths plus the hostile decoy in check 3 mitigate daemon replacement; any decoy execution blocks acceptance.
- **High — Information disclosure/Elevation, cross-user socket or state exposure:** retain daemon-enforced `0700` socket parent, `0600` socket, same-user XDG roots, and active/stale socket identity refusal; check 3 must observe isolation and no takeover.
- **High — Tampering/Denial of service, orphan or cross-invocation daemon ownership:** launcher cleanup/reaping plus sequential, interrupt, and shared-XDG parallel probes in check 3 mitigate unbounded lifetime and takeover; any surviving child or displaced owner blocks acceptance.
- **High — Tampering, package-input drift:** locked/offline PNPM and Cargo resolution, real fixed-output hashes, unchanged locks/pins, fixture digest checks, and closure/source comparison in checks 1-2 mitigate untrusted or mismatched input substitution.
- **Medium — Build availability:** exact standard pinned-nixpkgs helper names and fixed-output hashes are resolved during focused realization; an unavailable helper or inconsistent lock stops implementation for source-grounded correction, never silent repinning. These ASVS L1 risks receive normal review; all high-risk mitigation failures block acceptance.
