## Trust Boundaries

| Boundary | Description |
|---|---|
| Manifests/scripts to command inventory | Untrusted or stale command names can create false gates unless tied to tracked origins and canonical argv. |
| Runtime/reviewer executable to evidence | PATH collisions, version drift, or opaque reviewer output can misattribute a result. |
| Implementation SHA to approved review stages | Reviews become stale after any byte change and reviewer identity can be falsely claimed. |
| Raw logs/review output to tracked baseline | Host paths, source excerpts, or sensitive material may cross into durable evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Spoofing | Codex/CodeRabbit/runtime identity | high | mitigate | Pin absolute path, version, executable hash, help fingerprint, invocation contract, and primary-versus-independent role. |
| T-04-02 | Tampering | staged review and final-SHA validity | high | mitigate | Bind each stage to input/effective SHA and evidence digest; any later commit invalidates all downstream evidence and reruns from the earliest invalid stage. |
| T-04-03 | Repudiation | CI/test coverage claims | medium | mitigate | Canonical command IDs, exact argv/status/duration/artifact digests, claim map, and explicit absent/unavailable rows. |
| T-04-04 | Denial of Service | hung command/reviewer | medium | mitigate | Bounded timeout, owned-child termination, partial artifact checksums, cancellation state, hash-bound restart. |
| T-04-05 | Information Disclosure | logs/review packets | medium | mitigate | Synthetic inputs, bounded excerpts, redaction, private raw retention, public checksums. |
| T-04-SC | Tampering | existing command/runtime closure | high | mitigate | No installs; reuse verified locks/runtime hashes from Plan 02 and reject command execution on drift. |
