<threat_model>
Security validation scope: OWASP ASVS Level 1, limited to current declared authority, identity, data, and execution boundaries.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Normative documents to executable source | Human intent and source behavior can drift; neither may silently impersonate the other. |
| UI to runtime/engine/plugin/helper | User-controlled content and actions cross into replaceable execution components and side effects. |
| Runtime to filesystem/media/process/automation | Paths, codecs/helpers, child processes, and automation cross host authority boundaries. |
| Profile/instance/project state to durable storage | Distinct identities and concurrent/interrupted writes can collide or corrupt retained data. |
| Source citations to published baseline | Stale heads or selective citations could misrepresent executable truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Spoofing | identity/profile/instance axes | high | mitigate | Separate axes, cite current selectors/consumers, record absent authentication/signing behavior, validate no aliasing claim. |
| T-03-02 | Tampering | durable project/profile data | high | mitigate | Register schema/version/canonicalization, observed paths, write ownership, interrupted/parallel behavior, rollback and residual gaps. |
| T-03-03 | Elevation | plugin/helper/process/automation boundary | high | mitigate | Enumerate call sites/argv/inputs/authority, current containment, ASVS-L1 validation, and unsupported isolation as residual risk. |
| T-03-04 | Information Disclosure | filesystem/media/storage/evidence paths | medium | mitigate | Classify data and paths, use synthetic fixtures, state retention/export/deletion authority, avoid unproven secrecy claims. |
| T-03-05 | Repudiation | source-grounded authority claims | medium | mitigate | Bind claims to one Git tree and blob/line anchors, record confidence/contradictions, stop on head drift. |
| T-03-SC | Tampering | existing source/runtime inputs | high | mitigate | No installs or source changes; bind claims to one current Git tree and current lock/source identities, keeping consumed Plan-02 measurements separately labeled and unable to replace source citations or Track-A truth. |
</threat_model>
