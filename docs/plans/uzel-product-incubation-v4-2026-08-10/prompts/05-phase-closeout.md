Work on the final candidate SHA of the current bounded phase before final remote review
and merge. Do not add product scope.

Read the phase issue/plan, changed source/tests/schemas, canonical exact-byte
compatibility profile/hash scheme/hash and generated view, phase-pinned toolchain record,
candidate-next result, affected capability ledgers, canonical terminology registry, current ADR/SIR/upstream/learning
records, raw `.planning/learnings` extraction when present, and
`08-DECISIONS-LEARNING.md`.

Reconcile what the phase actually proved. Then:

1. update every affected capability ledger with honest before/after maturity and exact
   evidence; do not promote from a happy path alone;
2. create or supersede an ADR for any durable owner/trust/schema/profile/process choice;
3. create/update a Spec Interpretation Record for moving or contradictory upstream
   semantics;
4. update upstream/local-patch records through their real state—do not call an upstream
   merge adopted until Uzel pins and verifies it;
5. run/inspect the phase GSD learning extraction when supported, then explicitly promote,
   retain, reject, deduplicate or embargo each material item; capture reusable non-obvious
   failure, negative result or nuance as a Learning Note;
6. record these closeout deltas, allowing `none — reason`:

   ```text
   Decision delta:

   Upstream/local-patch delta:
   Learning delta:

   ```

7. verify human/agent docs use canonical term IDs, do not contradict source, tests,
   schemas, canonical profile or packaged behavior, and link every promoted non-elementary
   teaching claim to an exact executable/inspectable witness;
8. at a milestone endpoint invoke the separate milestone-learning prompt; otherwise keep
   educational work as a traceable seed;
9. regenerate visibility-aware internal/public knowledge indexes and prove the public
   index excludes internal/embargoed records;
10. run links/fences/docs, architecture-boundary and all affected tests;
11. report exact files changed, toolchain/profile identities and unresolved owned trigger.

Do not duplicate living upstream specs, rewrite old ADRs, manufacture a lesson, or add
unreviewed AI prose as architecture authority.
